Import Nama Tamu

1. Import dari Teks — Ketik atau tempel nama, satu per baris atau pisah dengan koma.

2. Import dari File Excel / CSV / TXT — Seret file ke kotak di bawah atau klik untuk memilih.

Klik atau seret file ke sini
Mendukung: .xlsx   .xls   .csv   .txt

Kolom bernama Nama, Name, atau Tamu otomatis terdeteksi. Jika tidak ada, kolom pertama digunakan. Nama duplikat otomatis dilewati saat mode "Tambahkan Saja".

Pilih Format Export

Export daftar tamu beserta link undangan dan link pesan WhatsApp ke berbagai format file.

📊

Excel (.xlsx)

File Microsoft Excel berisi kolom: No, Nama Tamu, Link Undangan, Link Pesan WA.

📄

CSV (.csv)

Format CSV dengan UTF-8 BOM, kompatibel dengan Excel dan Google Sheets.

📋

Salin ke Google Sheets

Salin semua data berformat tab-separated, langsung paste ke Google Sheets.

💬

Semua Pesan WhatsApp

Salin semua pesan WA lengkap siap kirim untuk semua tamu ke clipboard.

Cara Otomatis dengan Google Sheets

Jika Anda memiliki daftar nama tamu di Google Sheets (kolom A = nama tamu), gunakan dua rumus berikut:

📌 Kolom B — Rumus Link Undangan:

Paste di kolom B2, lalu tarik ke bawah untuk semua baris tamu.

💬 Kolom C — Rumus Teks Pesan WA Lengkap:

loading...

Paste di kolom C2. Setiap sel akan berisi teks pesan WA lengkap siap kirim untuk masing-masing tamu.
